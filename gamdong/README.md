# 감동 투표 — 노래 경연 관객 투표 앱

관객이 휴대폰으로 "감동 받았어요" 버튼을 누르면 인원이 집계되고, 무대 화면에서 방송처럼 숫자가 올라가며 공개된 뒤 순위표로 이어지는 웹앱입니다.

## 화면 구성

| 파일 | 누가 보나 | 하는 일 |
|---|---|---|
| `index.html` | 관객 (휴대폰) | 지금 무대 확인, 감동 버튼 누르기 (무대마다 1기기 1표) |
| `stage.html` | 빔프로젝터 | QR코드, 참가자 소개, 투표 중 연출, 카운트업 결과, 순위표 |
| `admin.html` | 진행자 (노트북/태블릿) | 참가자 등록, 단계 진행, 실시간 표 수 확인, 초기화 |

## 1. 먼저 미리보기 (데모 모드)

`js/config.js`의 `apiKey`가 비어 있으면 데모 모드로 동작합니다. 서버 없이 **한 컴퓨터의 브라우저 탭끼리만** 연동되므로 리허설과 화면 확인용입니다.

1. 폴더를 그대로 GitHub Pages에 올리거나, 크롬에서 `admin.html`을 엽니다.
2. 진행자 화면 위쪽의 **무대 화면 열기**, **관객 투표 화면**을 눌러 탭을 엽니다. (관객 탭을 여러 개 열면 각 탭이 관객 1명)
3. '데모 도구'의 가상 관객 버튼으로 표를 채워 결과 연출을 확인할 수 있습니다.

## 2. 실제 투표용 Firebase 연결 (무료, 약 10분)

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다).
2. **빌드 → Authentication → 시작하기 → 로그인 방법**에서 두 가지를 **사용 설정**
   - **Google** (진행자 로그인용)
   - **익명** (관객 투표용 — 관객은 로그인 없이 투표합니다)
3. **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 싱가포르 권장, **잠금 모드**로 시작).
4. Realtime Database의 **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고, `ADMIN_EMAIL`을 진행자 구글 이메일로 바꾼 뒤 **게시**.
5. **프로젝트 설정(톱니바퀴) → 내 앱 → 웹(`</>`) 앱 추가** → 나오는 `firebaseConfig` 값을 `js/config.js`에 옮겨 적습니다. `databaseURL`이 꼭 들어가야 합니다(없으면 Realtime Database를 만든 뒤 설정 화면을 새로고침).
6. `js/config.js`의 `adminEmail`도 같은 이메일로 바꿉니다.
7. GitHub Pages에 폴더 전체를 올린 뒤, **Authentication → 설정 → 승인된 도메인**에 `아이디.github.io`를 추가합니다.

## 3. 행사 당일 진행 순서

1. 진행자 화면(`admin.html`)에서 구글 로그인 → 참가자·행사 제목 확인
2. 리허설 후 **모든 투표·결과 초기화**, **접속 기기 수 초기화**
3. 빔프로젝터에 `stage.html`을 띄우고 `F` 키로 전체 화면 → **화면을 한 번 클릭해서 소리 켜기**(오른쪽 아래 '소리 켜짐' 확인, `M` 키로 끄고 켜기) → 관객이 QR로 접속
4. 참가자마다: **무대 준비 → 투표 시작(노래 시작) → 투표 마감 → 다음 참가자** (결과는 공개하지 않음)
5. 마지막 무대 뒤 **최종 결과 발표 (TOP 3)**: 게이지 상승음·순위 확정음·팡파르와 박수 소리와 함께 TOP 3만 공개

- 표 수와 전체 순위는 진행자 화면에서만 보입니다. 4위부터는 무대 화면에 나오지 않습니다.
- 투표를 마감하는 순간의 표 수가 기록됩니다. 잘못 진행했다면 **이 참가자 재투표**.
- **기준 관객 수**: 0이면 투표를 마감하는 순간 투표 화면을 켜 두고 있는 기기 수로 계산합니다. 정확한 관객 수를 알면 직접 입력하세요.

## 꼭 확인할 점

- **동시 접속 한도**: Firebase 무료(Spark) 요금제의 Realtime Database는 동시 접속 100개까지입니다. 관객이 100명을 넘으면 **Blaze(종량제)** 로 전환해야 합니다(동시 접속 200,000개). 이 앱의 사용량은 무료 포함량(월 10GB 다운로드, 1GB 저장) 안에 들어가지만 결제 카드 등록이 필요하니 예산 알림을 작게 걸어 두세요.
- **소리**: 브라우저 정책상 무대 화면을 한 번 클릭해야 소리가 납니다. 노트북 소리가 강당 스피커로 나가는지 리허설 때 꼭 확인하세요.
- **중복 투표**: 브라우저마다 1표입니다. 시크릿 창이나 다른 브라우저로 다시 투표하는 것까지 완전히 막지는 못합니다.
- **네트워크**: 체육관·강당은 와이파이가 약할 수 있으니 리허설 때 관객석에서 휴대폰 데이터로 접속해 보세요.
