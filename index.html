3D 과학 실험실

학년별·단원별 3D 수업 콘텐츠를 모아 둔 곳이에요. 콘텐츠를 눌러 바로 열거나, ‘QR’ 버튼으로 휴대폰·태블릿 접속 코드를 크게 띄울 수 있어요.

새 콘텐츠 추가하기 (선생님용)
  1. 새로 만든 웹앱 파일(예: circuit.html)을 GitHub 저장소에 올려요. 화면 사진을 쓰려면 thumbs 폴더에 같은 이름의 .jpg도 올려요. 사진이 없으면 제목 글자로 대신 보여 줘요.
  2. 저장소에서 index.html을 열고 연필 아이콘(편집)을 눌러요.
  3. 아래쪽 const APPS = [ 목록에 다음 한 덩어리를 복사해 붙이고 내용을 바꿔요. unit에는 단원 id('교육과정-학년-단원번호', 예: '2022-2-7' = 2022 개정 2학년 Ⅶ단원)를 적어요. 두 교육과정에 모두 보이게 하려면 unit: ['2015-3-5', '2022-3-4']처럼 함께 적어요. 새 단원이면 const UNITS = [에도 한 줄 추가해요.
  4. Commit changes를 누르고 1~2분 기다리면 이 페이지에 새 카드가 나타나요.

잠깐 숨기기 · 지우지 않고 첫 화면에서만 내리려면, APPS 목록에서 그 콘텐츠 덩어리 안에 hidden: true, 한 줄을 넣고 Commit changes를 눌러요. 파일과 주소는 그대로라서 이미 나눠 준 QR은 계속 열려요. 다시 보이게 하려면 그 줄을 지워요.

  hidden: true,
{
  file: 'circuit.html',            // 올린 파일 이름
  unit: '2022-2-7',                // 단원 id (교육과정-학년-단원번호)
  title: '전기 회로 3D',
  desc: '한두 문장으로 무엇을 할 수 있는지 적어요.',
  tags: ['옴의 법칙', '직렬·병렬'],
  thumb: 'thumbs/circuit.jpg',     // 없으면 이 줄을 지워요
  // hidden: true,                 // 숨기려면 맨 앞 // 를 지워요
},
{ id: '2022-3-1', cur: '2022', grade: 3, no: 'Ⅰ', name: '단원 이름' },

휴대폰·태블릿 카메라로 찍어서 들어오세요
